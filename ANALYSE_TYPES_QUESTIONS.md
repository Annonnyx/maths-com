1. **Progression logique** : Chaque classe ajoute 1-2 nouveaux types de questions
2. **Cohérence pédagogique** : Les cours correspondent parfaitement aux types de questions
3. **Explications complètes** : Tous les types de questions ont des explications détaillées
4. **Diversité** : 27 types de questions au total pour couvrir tous les niveaux
